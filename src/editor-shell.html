Exportar

JSON e SVGs do diagrama podem ser reabertos para edição neste editor. Compartilhe HTML para preservar animações e reações; leitores que exibem SVG como imagem podem bloquear scripts. PNG e PDF são estáticos.

PNG exporta a 300 dpi (até 16 MP). Todos os marcadores começam em 1 rem e podem ser ajustados na legenda. Fontes baixadas são incorporadas quando disponíveis.
