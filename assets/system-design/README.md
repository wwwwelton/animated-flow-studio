# Animated Flow Studio — System Design

81 símbolos SVG originais em arquivos individuais: 74 conceitos dos 75 termos numerados do PDF fornecido pelo usuário (Disponibilidade, termos 38 e 67, foi unificada) e sete protocolos de API (REST, GraphQL, gRPC, WebSockets, Webhooks, SSE e MQTT). Não são extrações nem cópias dos desenhos do PDF.

Cada SVG tem viewBox 0 0 64 64 e fundo transparente. Para mudar a cor, edite style="color:#334155" na raiz. O manifesto descreve categorias, tipos, termos de referência e a configuração de cada nó para Animated Flow Studio 2.3.

No editor atualizado: Componentes → Biblioteca → System Design. Selecione o símbolo no desenho para mudar cores ou exportá-lo com rótulo e tamanho personalizado. O ZIP só de símbolos não é importado pelo comando Abrir projeto JSON; use os projetos em examples/ no pacote completo.
